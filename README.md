# 💰 Expense Tracker

A colorful, animated web application to record income and daily expenses, track the remaining balance, and view spending reports with charts.

## 🔗 Live Demo
- https://digital-expensetrack-pro.vercel.app
- https://jayaraj2005.github.io/expense-tracker/

## ✨ Features
- Add income and expenses with amount, category, description and date
- Expense categories: Food, Travel, Shopping, Rent, Bills, Education, Medical, Others
- Dashboard with total income, total expenses and balance (Income − Expenses)
- Animated counters, gradient cards and smooth page transitions
- Transactions page with delete option and filters by type and month
- Reports page with a category-wise doughnut chart and a monthly income vs expenses bar chart
- Data saved in the browser using localStorage
- Responsive design for mobile and desktop

## 🛠️ Technologies Used
- HTML5
- CSS3 (gradients, animations, flexbox and grid)
- JavaScript (ES6)
- Chart.js for charts
- localStorage for data storage
- GitHub for version control
- Vercel and GitHub Pages for deployment

## 🚀 How to Run Locally
1. Download or clone this repository.
2. Open index.html in any modern browser.
3. Start adding your income and expenses.

## 📖 How It Works
1. The user adds an income or expense transaction.
2. JavaScript stores it in localStorage.
3. Totals and balance are calculated automatically.
4. The dashboard and charts update instantly.

## ⚠️ Limitations
- Data is stored only in the browser being used.
- There is no user login or cloud database.
